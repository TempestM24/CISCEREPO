# CISCEREPO
The whole point of this project being created is to serve as a base platform for the students of ICSE/ISC in general CISCE.
The platform aims to organise a clean and maintained repository of files pertaining the the CISCE such as Syllabus, Notes, Exam Papers etc.
The goal is to serve the students and the betterment of the CISCE community.
Please note that we are not in any way affiliated with the Council for the Indian Secondary Certificate Examinations, we are an independent team of students devleoping this project solely for the purpose of other students.
Enjoy your time on this repo.
